# Logo drop folder

Drop the evo symbol PNGs here, using these **exact filenames** (overwrite the
transparent placeholders that are currently in this folder):

| Filename | Use | Notes |
|----------|-----|-------|
| `evo-symbol-white.png` | **Currently used in the hero** (dark background) | The night-mode / white (light) version that blends with the dark background. |
| `evo-symbol-black.png` | For light backgrounds (future use) | The dark version. Not yet placed anywhere — here so it's ready. |

Tips:
- **Transparent background** (the hero sits on a dark gradient).
- A square-ish or wide PNG works; the hero scales it to a fixed height, so width is flexible.
- Suggested size: at least ~400px on the short edge for crispness on retina screens.

The hero currently shows nothing (an invisible 1×1 placeholder) until you replace
`evo-symbol-white.png` — so there's no broken-image icon in the meantime. As soon as
you drop the real file in with that name, it appears automatically. No code change needed.
